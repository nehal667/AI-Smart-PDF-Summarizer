# AI-Smart-PDF-Summarizer
AI Smart PDF Summarizer is a web application that allows users to upload and summarize documents including PDF, DOCX, TXT, and other text-based formats. The app uses Streamlit for the frontend and integrates LangChain with OpenAI's language models to generate concise, meaningful summaries.

Features
> Supports multiple document types: PDF, DOCX, TXT, etc.

> Modular architecture for file processing and summarization

> Uses LangChain with OpenAI GPT models for natural language summarization

> Token counting and optimization for efficient API usage

> Simple and interactive Streamlit interface
